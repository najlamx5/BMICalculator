# BMI Calculator – AI-Enhanced Health Awareness Application

## Project Overview

The **BMI Calculator** is a user-friendly web application developed with **Python and Streamlit** to calculate Body Mass Index (BMI) and provide basic health-awareness information.

The application allows users to enter their **age, sex, height, and weight manually**, or upload an image containing measurement information. Using **OCR (Optical Character Recognition)**, the application can extract available information such as height, weight, age, and sex and automatically fill the BMI form.

The application calculates the user's **BMI, BMI category, ideal weight, healthy weight range, and estimated daily calorie requirement**. A Reset function allows users to quickly return the application to its default state.

As part of the Generative AI capstone project, the application can also be extended with a **Retrieval-Augmented Generation (RAG)** knowledge base containing verified health-awareness documents. The RAG component can retrieve relevant information and generate grounded responses to user questions.

## Key Features

* BMI calculation using height and weight
* Support for kilograms/pounds
* Support for centimeters and feet/inches
* Image upload and OCR text extraction
* Automatic detection of height and weight
* **Auto Fill Form** functionality
* BMI category classification
* Ideal and healthy weight range
* Estimated daily calorie requirement
* User-friendly Streamlit interface
* Reset application functionality
* RAG-based health-awareness information
* Designed for online deployment

## Project Objective

The main objective is to demonstrate how Python, Streamlit, OCR, and Generative AI/RAG technologies can be combined to create a practical, accessible health-awareness application.

## Important Notice

This application is intended for **educational and health-awareness purposes only**. BMI is a screening measure and the application should not be considered a substitute for professional medical advice.
